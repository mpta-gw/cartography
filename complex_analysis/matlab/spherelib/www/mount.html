How I mounted my SanDisk Cruzer thumb drive

Look at /proc/bus/usb, mount /dev/sda1 /mnt/ubsname, look at /etc/mtab, etc. It all works in a snap. Cruzer is vfat.

How to mount a file system

fstab is used by the mount command to know what filesystems go on what mount points, mostly for mounting them at startup. mtab is used to keep track of what filesystems are mounted, right now. So if you want to to automount upon startup need to update /etc/fstab with the results of /etc/mtab after mounting, say, the Windows partition.

On my machine:
  1. Create /mnt/whatever directory. In this case: /mnt/dalilocal
  2. Add the following line to /etc/fstab:
    • dali:/usr/local /mnt/dalilocal nfs exec,dev,suid,rw,bg,soft,intr 0 0
  3. Some of this might be redundant but doesn't hurt:
    • Update my /etc/hosts with
      • 192.168.0.25 dali.geophysics.princeton.edu dali
    • Update /etc/hosts.allow with
      • ALL: 192.168.0.25
    • Update /etc/hosts.deny with
      • ALL:ALLatALL
      to deny access to all others
On the machine whos disks are to be mounted on my machine:
  1. Log in to it using rlogin and become superuser with su
    • Update its /etc/hosts file with
      • 192.168.0.46 melchior.geophysics.princeton.edu melchior
    • Update its /etc/hosts.allow file with
      • ALL: 192.168.0.46
    • Update /etc/exports by adding
      • /usr/local melchior.geophysics.princeton.edu(rw)
  2. Run exportfs -av. This will update /var/lib/nfs/xtab by adding my info like:
    • /usr/local melchior.geophysics.princeton.edu (rw,async,wdelay,secure,root_squash,no_all_squash,mapping=identity,anonuid=-2,anongid=-2)
  3. Might have a problem that requires restarting nfs file servers and portmap utilities:
    • /etc/rc.d/init.d/nfs restart
    • /etc/rc.d/init.d/nfslock restart
    • /etc/rc.d/init.d/portmap restart
On my machine:
  1. Run mount -av to activate or explicitly: mount dali:/usr/local /mnt/dalilocal.
  2. mount by itself will give you a status.
Got errors about RPC, portmap, etc. Was not working. The problem: Needed to turn off ipchains (which determines how the firewall is implemented) on my machine on all levels. See under network. Mount then worked. Second time, got complaint that mount: RPC: Program not registered. Explicitly adding dali into my /ect/hosts.allow file didn't help. Went through the steps above and did everyting explicitly (without assuming anything would be redundant) and it worked beautifully.
